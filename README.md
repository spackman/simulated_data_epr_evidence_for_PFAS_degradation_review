# EPR Fitting for "Experimental Evidence of AOP/ARP Mechanisms by EPR"
*created December 23, 2025 by Isaac Spackman*  
  
This repository contains MATLAB code and raw data used in re-fitting experimental data for the scoping review "Experimental Evidence of AOP/ARP Mechanisms by EPR". All experimental data was extracted from published figures using webplotdigitizer(link) with no smoothing/ averaging.  
  
Fitting is performed with EasySpin <version>. Final plots were prepared for publication in Python.
